데비안 및 우분투

공식 저장소 사용하기 (권장됨)

우리는 사용자의 다른 시스템 업데이트와 함께 자동 업데이트를 허용하는 데비안 및 우분투 기반 배포를 위한 저장소를 제공합니다. 저장소를 사용하려면:

  1. 사용자의 터미널을 엽니다 (CTRL+ALT+T가 작동해야 함)
    • 우분투 전용 * - 우분투 “universe” 저장소([GUI 기반 접근 방식])(https://askubuntu.com/a/148645) 또는 CLI-기반 접근방식을 사용할 수 있음)를 활성화합니다.
  3. 저장소 설정 스크립트 다운로드:
    curl https://raw.githubusercontent.com/jamulussoftware/jamulus/main/linux/setup_repo.sh > setup_repo.sh
  4. 스크립트를 실행 가능하게 만들기:
    chmod +x setup_repo.sh
  5. 설정 스크립트를 실행하고 Jamulus 설치하기:
    sudo ./setup_repo.sh && sudo apt install jamulus

.deb 파일 수동 설치하기

  1. 사용자의 아키텍처에 맞는 Jamulus 다운로드: amd64, armf or arm64
    • 우분투 전용 * - 우분투 “universe” 저장소([GUI 기반 접근 방식])(https://askubuntu.com/a/148645) 또는 CLI-기반 접근방식을 사용할 수 있음)를 활성화합니다.
  3. 콘솔 창을 열고(CTRL+ALT+T가 작동해야 함) sudo apt-get update를 입력하여 apt를 업데이트합니다
  4. 설치 프로그램을 다운로드한 위치로 이동하여 두 번 클릭하거나, 명령줄을 사용합니다. sudo apt install ./jamulus_3.12.5_ubuntu_amd64.deb(또는 위와 같이 Raspberry Pi 등의 경우)
  5. 설치한 후에는 파일을 삭제하고 모든 콘솔 창을 닫을 수 있습니다.

업그레이드: Jamulus를 최신 버전으로 업그레이드하고 Jamulus를 수동으로 설치해야 하는 경우, 새 .deb 파일을 다운로드하고 위와 같이 다시 설치하면 됩니다.

다른 배포판

다른 배포판의 설치 프로그램은 패키지 관리자 및 Repology를 참조하십시오. 최신 버전의 Jamulus가 배포판에 포함되어 있지 않은 경우 소스에서 Jamulus 컴파일을 할 수 있습니다. 제공된 설치 스크립트도 참고하십시오.

사용자의 하드웨어 설정

Jamulus 클라이언트는 시작하려면 실행 중인 JACK 서버에 연결해야 합니다. 배포판에 적합한 로우 레이턴시 사운드 서버를 찾아야 합니다. - 배포판에서 JACK을 사용하는 경우 QjackCtl로 JACK 구성 방법을 참조하세요. - 배포판에서 PipeWire를 사용하는 경우 PipeWire 구성 방법을 참조하세요.

QjackCtl로 JACK 구성하기

JACK 서버를 실행하려면 QjackCtl을 사용하는 것이 좋습니다.

  1. QjackCtl을 실행합니다. Qt JACK 컨트롤 유틸리티 메인 페이지가 표시됩니다**.
  2. 다음과 같이 사용자의 사운드 하드웨어 구성:
  • 오디오 인터페이스를 원하는 것으로 설정합니다(목록에 여러 개 있을 수 있음 - Jamulus와 JACK을 멈추지 않고는 변경할 수 없으므로 올바른 것을 선택하세요).
  • 샘플 레이트를 48000으로 지정합니다.
  • 프레임/주기를 128로, 처음에는 주기/버퍼를 2로 지정합니다.

새로운 설정을 적용하려면 JACK을 다시 시작하고 아래 Jamulus 시작 섹션부터 계속하세요.

PipeWire 구성하기

PipeWire는 자체 JACK 서버를 제공합니다. Jamulus Client를 실행하면 PipeWire는 자동으로 JACK 서버를 실행합니다. 그러나 조정해야 할 몇 가지 매개변수가 있습니다. 오디오 인터페이스를 “프로 오디오” 프로필로 설정하고 PipeWire의 “rate” 및 “quantum” 매개변수를 미리 정의해야 합니다. PipeWire wiki에서 구성에 대한 자세한 정보를 찾을 수 있습니다.

시스템을 설정하려면: 1. pavucontrol(오디오 믹서)을 열고 구성 탭에서 사운드 하드웨어에 대한 “pro-audio” 프로필을 선택합니다. 2. 터미널에서 다음 두 명령을 사용하여 PipeWire의 rate와 quantum을 강제로 적용합니다:

pw-metadata -n settings 0 clock.force-rate 48000
pw-metadata -n settings 0 clock.force-quantum 128

그 후 아래의 Jamulus 시작하기 섹션부터 계속 진행하세요.

Jamulus 시작하기

JACK 또는 PipeWire를 구성한 후 Jamulus를 실행합니다.

문제가 있는 경우 먼저 문제해결 페이지를 확인해 주세요.
