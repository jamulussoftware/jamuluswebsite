Installation auf Linux

Stelle sicher, dass du die Erste Schritte Seite bereits gelesen hast.

Updatest du? Es macht Sinn die Konfiguration zu sichern.

Installierst du einen Server? Lies zuerst die Anleitung für Serveradministratoren

Debian und Ubuntu

Nutze die offizielle Paketquelle (empfohlen)

Wir stellen Paketquellen für Debian und Ubuntu-basierte Distributionen zur Verfügung. Dadurch werden automatische Upgrades neben den Systemupdates möglich. Um diese zu nutzen, folgen diesen Anweisungen:

  1. Öffne dein Terminal (z.B. mit STRG+ALT+T)
  2. Nur Ubuntu - Aktiviere das Ubuntu “universe” repository (Du kannst dazu die GUI Methode oder die CLI Methode nutzen).
  3. Lade das Skript für die Paketquellen herunter:
    curl https://raw.githubusercontent.com/jamulussoftware/jamulus/main/linux/setup_repo.sh > setup_repo.sh
  4. Mache das Skript ausführbar:
    chmod +x setup_repo.sh
  5. Führe das Setup-Skript aus und installiere Jamulus:
    sudo ./setup_repo.sh && sudo apt install jamulus

.deb Dateien manuell installieren

  1. Downloade Jamulus für deine Architektur: amd64, armf oder arm64
  2. Nur Ubuntu - Aktiviere das Ubuntu “universe” repository (Du kannst dazu die GUI Methode oder die CLI Methode nutzen).
  3. Aktualisiere apt, indem du dein Terminal öffnest (STRG+ALT+T sollte funktionieren) und folgendes eingibst: sudo apt-get update
  4. Wechsle in das Verzeichnis in das du das Installationsprogramm gespeichert hast und doppelklicke darauf, oder verwende die Befehlszeile: sudo apt install ./jamulus_3.12.2_ubuntu_amd64.deb (oder für Raspberry Pi etc. wie oben)
  5. Sobald die Installation fertig ist, kannst du die Datei löschen und alle Terminalfenster schließen.

Upgrades: Wenn du Jamulus auf eine neue Version aktualisierst und Jamulus manuell installiert hast, kannst du die neue .deb Datei einfach herunterladen und wie oben beschrieben neu installieren.

Andere Distributionen

Für Installer auf anderen Distributionen, durchsuche die Paketverwaltung und Repology. Wenn keine aktuelle Jamulus Version in deiner Distribution enthalten ist, kannst du Jamulus kompilieren. Du kannst auch die inoffiziellen Installationsskripte nutzen.

Richte deine Hardware ein

Der Jamulus Client muss sich mit einem JACK Server verbinden, um verwendet werden zu können. Dazu musst du wissen, welcher low-latency sound Server auf deiner Distribution genutzt wird. - Falls deine Distro JACK nutzt, sieh dir JACK mit QjackCtl einrichten an. - Falls deine Distro PipeWire nutzt, findest du hier Informationen, wie du PipeWire konfigurierst.

Konfiguriere Jack mit QjackCtl

Um einen JACK Server zu nutzen, empfehlen wir QjackCtl.

  1. Öffne QjackCtl und warte, bis sich das Jack Audio Connection Kit öffnet.
  2. Konfiguriere deine Audiohardware wie folgt:
  • Wähle dein Audio Interface aus (es können mehrere in der Liste sichtbar sein) - Wähle das korrekte aus, weil es nicht geändert werden kann, ohne Jamulus und JACK zu beenden.
  • Setzte die Sample Rate auf 48000.
  • Setze die Frames/Period auf 128 und Periods/Buffer erst einmal auf 2.

Starte JACK neu, damit die neuen Einstellungen übernommen werden können. Danach mache in der Jamulus Starten Sektion unten weiter.

PipeWire konfigurieren

PipeWire provides its own JACK server. When you launch the Jamulus Client, PipeWire automatically runs a JACK server. However, there are a few parameters to adjust. You need to set your audio interface to the “pro-audio” profile and define PipeWire’s “rate” and “quantum” parameters beforehand. You can find more information about the configuration in the PipeWire wiki.

To set up your system: 1. Open pavucontrol (the audio mixer) and choose the “pro-audio” profile for your sound hardware in the configuration tab.

  1. In a terminal use the following two commands to force PipeWire’s rate and quantum: 
    pw-metadata -n settings 0 clock.force-rate 48000
pw-metadata -n settings 0 clock.force-quantum 128

    After this, continue from the Start Jamulus section below.

Jamulus starten

Sobald JACK bzw. PipeWire läuft und konfiguriert ist, starte Jamulus.
