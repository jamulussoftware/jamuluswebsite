การติดตั้งบน Linux

โปรดแน่ใจว่าคุณได้อ่านหน้า เริ่มต้นใช้งาน แล้ว

อัปเกรดเวอร์ชัน? คุณอาจต้องการสำรองข้อมูลการตั้งค่าของคุณ ก่อน

ติดตั้งเซิร์ฟเวอร์? อ่านคู่มือสำหรับผู้ดูแลเซิร์ฟเวอร์ ก่อน

Debian และ Ubuntu

ใช้ Repository อย่างเป็นทางการ (แนะนำ)

เรามี repository สำหรับ Debian และ Ubuntu ที่ช่วยให้คุณสามารถอัปเดตโปรแกรม Jamulus ได้โดยอัตโนมัติพร้อมกับการอัปเดตระบบอื่นๆ วิธีการใช้ repository:

  1. เปิด Terminal (คีย์ลัด CTRL+ALT+T)
  2. เฉพาะ Ubuntu - เปิดใช้งาน repository “universe” ของ Ubuntu (คุณสามารถใช้ เปิดใช้งานผ่าน GUI หรือ เปิดใช้งานด้วยคำสั่งใน Terminal)
  3. ดาวน์โหลดสคริปต์ตั้งค่า repository:
    curl https://raw.githubusercontent.com/jamulussoftware/jamulus/main/linux/setup_repo.sh > setup_repo.sh
  4. ตั้งค่าให้สคริปต์สามารถรันได้:
    chmod +x setup_repo.sh
  5. รันสคริปต์ตั้งค่าและติดตั้ง Jamulus:
    sudo ./setup_repo.sh && sudo apt install jamulus

ติดตั้งไฟล์ .deb ด้วยตนเอง

  1. ดาวน์โหลด Jamulus สำหรับสถาปัตยกรรมของคุณ: amd64, armf หรือ arm64
  2. เฉพาะ Ubuntu - เปิดใช้งาน repository “universe” ของ Ubuntu (คุณสามารถใช้ เปิดใช้งานผ่าน GUI หรือ เปิดใช้งานด้วยคำสั่งใน Terminal)
  3. อัปเดต apt โดยเปิดหน้าต่าง Terminal (คีย์ลัด CTRL+ALT+T) แล้วพิมพ์: sudo apt-get update
  4. ไปที่โฟลเดอร์ที่คุณดาวน์โหลดไฟล์ติดตั้งไว้ จากนั้นดับเบิลคลิกที่ไฟล์ หรือใช้คำสั่ง: sudo apt install ./jamulus_3.12.4_ubuntu_amd64.deb (หรือสำหรับ Raspberry Pi ฯลฯ ตามข้างต้น)
  5. เมื่อติดตั้งเสร็จแล้ว คุณสามารถลบไฟล์และปิดหน้าต่างคอนโซลได้

การอัปเกรด: หากคุณต้องการอัปเกรด Jamulus เป็นเวอร์ชันที่ใหม่กว่าและติดตั้ง Jamulus ด้วยตนเอง เพียงดาวน์โหลดไฟล์ .deb ใหม่ แล้วติดตั้งใหม่อีกครั้งตามขั้นตอนข้างต้น

ดิสทริบิวชันอื่นๆ

สำหรับตัวติดตั้งบนดิสทริบิวชันอื่นๆ ให้ดูที่ตัวจัดการแพ็กเกจของดิสทริบิวชันนั้นๆ และ Repology หากดิสทริบิวชันของคุณไม่มี Jamulus เวอร์ชันล่าสุด คุณสามารถคอมไพล์ Jamulus จากซอร์สโค้ด ได้ และลองดูสคริปต์การติดตั้ง ที่ผู้ใช้คนอื่นๆ สร้างขึ้น

การตั้งค่าฮาร์ดแวร์

ไคลเอนต์ Jamulus จำเป็นต้องเชื่อมต่อกับเซิร์ฟเวอร์ JACK ที่กำลังทำงานอยู่จึงจะเริ่มทำงานได้ คุณต้องตรวจสอบว่าเซิร์ฟเวอร์เสียงแบบ low-latency สำหรับดิสทริบิวชันของคุณคือตัวไหน - หากดิสทริบิวชันของคุณใช้ JACK ให้ดูวิธี กำหนดค่า JACK ด้วย QjackCtl - หากดิสทริบิวชันของคุณใช้ PipeWire ให้ดูวิธี กำหนดค่า PipeWire

การกำหนดค่า JACK ด้วย QjackCtl

วิธีที่แนะนำสำหรับการรันเซิร์ฟเวอร์ JACK คือการใช้ QjackCtl

  1. เปิด QjackCtl ขึ้นมา คุณจะเห็น Qt JACK Control utility main page
  2. กำหนดค่าอุปกรณ์เสียงของคุณดังนี้:
  • ตั้งค่า Interface เสียง ให้ตรงกับอุปกรณ์ที่คุณต้องการใช้ (อาจมีหลายตัวเลือกในรายการ ให้เลือกอันที่ถูกต้อง เพราะระหว่างที่ Jamulus และ JACK ทำงานคุณจะไม่สามารถเปลี่ยนแปลงการตั้งค่านี้ได้)
  • ตั้งค่า Sample Rate เป็น 48000
  • ตั้งค่า Frames/Period เป็น 128 และ Periods/Buffer เป็น 2 ในตอนแรก

รีสตาร์ท JACK เพื่อให้การตั้งค่าใหม่มีผล จากนั้นไปที่หัวข้อ เริ่ม Jamulus ด้านล่าง

การกำหนดค่า PipeWire

PipeWire มีเซิร์ฟเวอร์ JACK เป็นของตัวเอง เมื่อคุณเปิดไคลเอนต์ Jamulus ตัว PipeWire จะรันเซิร์ฟเวอร์ JACK โดยอัตโนมัติ อย่างไรก็ตาม มีพารามิเตอร์บางอย่างที่ต้องปรับแต่ง คุณต้องตั้งค่าออดิโออินเตอร์เฟสของคุณเป็นโปรไฟล์ “pro-audio” และกำหนดค่าพารามิเตอร์ “rate” และ “quantum” ของ PipeWire ไว้ล่วงหน้า คุณสามารถดูข้อมูลเพิ่มเติมเกี่ยวกับการกำหนดค่าได้ใน PipeWire wiki

วิธีตั้งค่าระบบของคุณ: 1. เปิด pavucontrol (โปรแกรมมิกซ์เสียง) แล้วเลือกโปรไฟล์ “pro-audio” สำหรับอุปกรณ์เสียงของคุณในแท็บการกำหนดค่า

  1. ใน Terminal ให้ใช้คำสั่งสองคำสั่งต่อไปนี้เพื่อบังคับค่า rate และ quantum ของ PipeWire: 
    pw-metadata -n settings 0 clock.force-rate 48000
pw-metadata -n settings 0 clock.force-quantum 128

    หลังจากนั้น ไปที่หัวข้อ เริ่ม Jamulus ด้านล่าง
