การติดตั้งบน Windows

โปรดแน่ใจว่าคุณได้อ่านหน้า เริ่มต้นใช้งาน แล้ว

อัปเกรดเวอร์ชัน? คุณอาจต้องการสำรองข้อมูลการตั้งค่าของคุณ ก่อน

  1. ดาวน์โหลดและติดตั้ง ASIO Driver หากผู้ผลิตฮาร์ดแวร์ของคุณได้จัดเตรียมไดรเวอร์ ASIO ไว้ให้ ขอแนะนำให้ลองใช้ไดรเวอร์นั้นดู แต่หากคุณหาไม่พบ หรือคุณไม่ได้ใช้ออดิโออินเตอร์เฟสแยก คุณอาจต้องติดตั้ง ASIO4ALL สำหรับข้อมูลเพิ่มเติม เลื่อนลงไปอ่านที่หัวข้อ ASIO
  2. ดาวน์โหลด Jamulus
    Mirror 2:SourceForge
  3. ติดตั้ง Jamulus: ดับเบิลคลิกที่ไฟล์ติดตั้งเพื่อเปิดใช้งาน หากคุณได้รับข้อความเตือนจาก SmartScreen ให้คลิกที่ “More info” และ “Run anyway” เพื่อติดตั้ง Jamulus (หากคุณดาวน์โหลด Jamulus เวอร์ชันใหม่ล่าสุด และเป็นหนึ่งในคนกลุ่มแรกๆ ที่ดาวน์โหลด ตัวโปรแกรม Jamulus อาจจะยังไม่ได้รับการรับรองจาก SmartScreen เนื่องจากเราไม่ได้จ่ายเงินสำหรับ code signing)
  4. เปิด Jamulus: ตอนนี้คุณควรจะสามารถใช้ Jamulus ได้เหมือนกับแอปพลิเคชันอื่นๆ
  5. ตั้งค่าการ์ดเสียงของคุณ: เมื่อติดตั้งเสร็จแล้ว คุณต้องตั้งค่าอุปกรณ์เสียงของคุณ และหากคุณกำลังใช้ ASIO4ALL โปรดดูวิธีการตั้งค่าด้านล่าง

** หมายเหตุ:** หากคุณไม่ต้องการใช้ ASIO หรือต้องการใช้ JACK บน Windows คุณสามารถใช้ Jamulus เวอร์ชัน JACK แทนได้ และคุณสามารถค้นหาเวอร์ชันเก่า (legacy) ที่รองรับระบบปฏิบัติการรุ่นเก่าๆ ได้ใน หน้า release บน GitHub.

ASIO

Jamulus สามารถใช้ ASIO ได้

  • หากคุณมีการ์ดเสียงหรือออดิโออินเตอร์เฟสแยก เราขอแนะนำให้ใช้งานไดรเวอร์ ASIO ของผู้ผลิตอุปกรณ์นั้นๆ หากเป็นไปได้ (เพราะไดรเวอร์เหล่านี้มักจะให้คุณภาพเสียงที่ดีที่สุด)
  • หากคุณไม่ได้ใช้การ์ดเสียงแยก คุณก็น่าจะไม่มีไดรเวอร์ ASIO ด้วย ดังนั้นคุณจะต้องติดตั้งไดรเวอร์ ASIO สำหรับอุปกรณ์ทั่วไป เช่น ASIO4ALL:

เว็บไซต์ ASIO4ALL

การตั้งค่า ASIO4ALL

คุณอาจจะต้องลองผิดลองถูกเล็กน้อย ขึ้นอยู่กับอุปกรณ์เสียงของคุณ หากทุกอย่างทำงานได้ตามปกติตั้งแต่แรก คุณก็ไม่จำเป็นต้องทำอะไรเพิ่มเติม

เคล็ดลับ: ตั้งค่าการ์ดเสียงของคุณในขณะที่คุณเชื่อมต่อกับเซิร์ฟเวอร์ เพื่อฟังเสียงเครื่องดนตรีหรือเสียงของคุณ และตรวจสอบว่าทุกอย่างถูกตั้งค่าอย่างถูกต้องหรือไม่ แต่อ่านเนื้อหาต่อไปนี้ให้จบก่อน

ก่อนที่คุณจะเริ่มต้นใช้งาน Jamulus:

  1. ปิดแอปพลิเคชันทั้งหมด (โดยเฉพาะแอปพลิเคชันที่สามารถเข้าถึงการ์ดเสียงของคุณได้ เช่น เบราว์เซอร์/โปรแกรมเล่นเพลง) ASIO4ALL จำเป็นต้องเข้าถึงการ์ดเสียงของคุณแบบเอกสิทธิ์เฉพาะ (exclusive) ซึ่งหมายความว่าโปรแกรมอื่นๆ จะไม่สามารถใช้เสียงได้ หาก ASIO4ALL และ Jamulus กำลังทำงานอยู่
  2. หากเสียงของ Jamulus ไม่ทำงาน ตรวจสอบให้แน่ใจใน ASIO4ALL ว่ามีเพียงอินพุต/เอาต์พุตที่ถูกต้องเท่านั้นที่เปิดใช้งานอยู่ ส่วนอื่นๆ ควรปิดทั้งหมด ค้นหารายการการการตั้งค่า ASIO4ALL ที่ใช้งานได้ของชุมชน สำหรับการตั้งค่าของคุณ หรือลองตั้งค่าด้วยตัวเองหากคุณหาของคุณไม่พบ:

คู่มือวิธีการตั้งค่าอินพุตใน ASIO4ALL

  1. เปิดหน้า Settings ของ Jamulus
  2. ไปที่ “ASIO Device Settings” (คอลัมน์ทางด้านซ้าย ใต้ตัวเลือกไดรเวอร์)
  3. เปิด advanced view ใน ASIO4ALL (คลิกที่ไอคอนรูปเครื่องมือที่ด้านล่างขวา)
  4. เปิดใช้งานเฉพาะการ์ดเสียงที่คุณต้องการใช้โดยคลิกที่ปุ่มถัดจากชื่อ
  5. เปิดดูอินพุต/เอาต์พุตของการ์ดเสียงของคุณโดยคลิกที่ ไอคอนเครื่องหมายบวก ถัดจากการ์ดเสียงนี้
  6. ต่อไป เปิดใช้งานอินพุต/เอาต์พุตที่ถูกต้องในรายการใต้การ์ดเสียงของคุณ และปิดส่วนอื่นๆ ทั้งหมด คุณสามารถเลื่อนเมาส์ไปวางเหนืออินพุต/เอาต์พุต เพื่อดูว่าเป็นอินพุตหรือเอาต์พุต และเช็คว่ามันรองรับ sample rate แบบ 48kHz (คุณภาพ DVD) ที่ Jamulus ต้องการหรือไม่

คำแนะนำ:

  1. ชื่อของอุปกรณ์เสียงที่ถูกต้องอาจจะไม่ชัดเจนเสมอไป การ์ดเสียงที่มากับเครื่องหลายตัวมักจะมีชื่อว่า “Realtek High Definition Audio”, “Conexant” หรือชื่ออื่นๆ ที่คล้ายกัน
  2. หูฟังและลำโพงมักจะมีชื่อว่า “output” และไมโครโฟนจะมีชื่อว่า “input” หรือ “capture”
  3. Stereo Mix/Stereo Input มักจะไม่ใช่อินพุต/เอาต์พุตที่คุณต้องการ ดังนั้น ให้ปิดมันหากคุณเห็น

การแก้ไขปัญหา

หากไม่มีอะไรได้ผล ให้ลองรีสตาร์ทโปรแกรม Jamulus และ/หรือ รีสตาร์ทเครื่องของคุณ เพื่อปิดโปรแกรมเบื้องหลังที่อาจกำลังเข้าถึงการ์ดเสียงของคุณ

หลังจากนั้น ให้ตั้งค่าอินพุต/เอาต์พุตอีกครั้ง โดย ASIO4ALL จะแสดงอินพุต/เอาต์พุตที่เปิดใช้งานได้ เป็นไอคอนปุ่มเปิดปิดและปุ่มเล่นที่มีไฟติด หากคุณเห็นเครื่องหมายกากบาทสีแดงหรือสัญลักษณ์สีเหลืองแทน ให้ปิดแอปพลิเคชันอื่นๆ ที่อาจกำลังเข้าถึงการ์ดเสียงของคุณ (เช่น เว็บเบราว์เซอร์, Zoom และอื่นๆ)

ลองดูวิดีโอนี้ โดย trombonepizza ซึ่งจะให้ข้อมูลโดยละเอียดเพิ่มเติมเกี่ยวกับการตั้งค่า ASIO4ALL

ข้อมูลเพิ่มเติมอย่างเป็นทางการเกี่ยวกับวิธีการกำหนดค่า ASIO4ALL สามารถดูได้ที่ ASIO4ALL FAQs บนเว็บไซต์ของ ASIO4ALL.
