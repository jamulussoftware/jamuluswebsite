Заявление о конфиденциальности

Английская версия этого документа представляет собой официальное заявление о конфиденциальности для текущей версии программного обеспечения, доступного на этом сайте. Более ранние версии программного обеспечения и неанглоязычные переводы данной политики конфиденциальности могут содержать иные условия, которые более не применяются или не поддерживаются

Определение терминов

  • “Сервер” ПО Jamulus, работающее в качестве сервера и принимающее соединения от клиентов
  • “Клиент” ПО Jamulus, используемое для подключения к серверу
  • “Каталог” Сервер Jamulus, настроенный на предоставление списка серверов клиентам

Jamulus.io Сайт

Сайт по адресу jamulus.io обслуживается с помощью GitHub Pages. Команда Jamulus не создавала сайт для установки отслеживающих куки-файлов, но смотрите политику конфиденциальности на Github для информации, касающейся сбора данных и конфиденциальности в целом. База знаний сообщества использует giscus для обсуждений и комментариев. Вы можете ознакомиться с Политикой конфиденциальности giscus на их репозитории GitHub.

ПО Jamulus

Jamulus - это ПО с открытым исходным кодом, которое может быть изменено любым человеком. В связи с этим проект Jamulus не может делать никаких заявлений, касающихся конфиденциальности, сбора данных или безопасности в связи с использованием вами этого ПО.

Общая информация

Under normal use with software downloaded from this website that has not been modified, your user profile information is exchanged with Servers you connect to, peers connected to those same Servers, and to third parties (including Directories) that use the Jamulus protocol. This information is limited to your Jamulus name, city, country, instrument, and skill level as you have set them in your profile. Directories from which you request Server lists, Servers displayed in the Connect Dialog and Servers you connect to will also have access to your internet address (IP Address) as it is required for the software to work; but this information is not shared with peers on the same Server or available to third parties.

Все сообщения между Клиентами, Серверами, Директориями и пользователями сторонних протоколов передаются без шифрования.

Серверы Jamulus

Когда вы подключаетесь к серверу напрямую или через каталог, оператор этого сервера несет ответственность за его политику работы, политику конфиденциальности и использования данных. Хотя не модифицированные серверы по умолчанию не регистрируют и не хранят информацию о вашем подключении или профиле, некоторые серверы могут быть настроены на это. Поэтому вы не должны рассчитывать на конфиденциальность в отношении информации вашего профиля или интернет-адреса.

Обмен чатами

Чаты - это текстовые сообщения, которыми могут обмениваться клиенты, подключенные к одному и тому же серверу. Все подключенные к Серверу могут видеть все чаты, поэтому не следует ожидать конфиденциальности в отношении информации, отправленной через функцию чата Jamulus. Хотя не модифицированные серверы не регистрируют и не хранят чаты, некоторые модифицированные серверы могут это делать.

Аудиозаписи

На не модифицированных серверах будет отображаться уведомление о включении записи. Записи каждого канала хранятся на сервере и контролируются оператором сервера.

Подключенные клиенты могут делать записи сеансов за пределами Jamulus, о чем может не быть никаких уведомлений или указаний. Jamulus не имеет возможности обнаружить или контролировать такие ситуации и не делает никаких заявлений относительно сбора или использования таких данных записи.

Справочники

Директории - это центральные точки подключения для определения местоположения серверов. Для удобства пользователей Jamulus Client поставляется с заранее определенным списком директорий. Эти каталоги работают независимо друг от друга, но представляются как запущенные не модифицированные версии ПО Jamulus. Если вы не хотите отправлять свою информацию в директории, вам придется подключаться к серверам напрямую.
