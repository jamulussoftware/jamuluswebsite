Debian и Ubuntu

Использование официального репозитория (рекомендуется)

Мы предоставляем репозиторий для дистрибутивов на базе Debian и Ubuntu, который позволяет автоматически обновлять систему наряду с другими обновлениями. Чтобы воспользоваться репозиторием:

  1. Откройте терминал (CTRL+ALT+T)
    • Только для Ubuntu* - Включите репозиторий “Вселенная” Ubuntu (можно использовать подход на основе графического интерфейса или подход на основе CLI).
  3. Загрузите скрипт настройки репозитория:
    curl https://raw.githubusercontent.com/jamulussoftware/jamulus/main/linux/setup_repo.sh > setup_repo.sh
  4. Сделайте скрипт исполняемым:
    chmod +x setup_repo.sh
  5. Запустите сценарий установки и установите Jamulus:
    sudo ./setup_repo.sh && sudo apt install jamulus

Ручная установка файлов .deb

  1. Скачайте Jamulus для вашей архитектуры: amd64, armf or arm64
    • Только для Ubuntu* - Включите репозиторий “Вселенная” Ubuntu (можно использовать подход на основе графического интерфейса или подход на основе CLI).
  3. Обновите apt, открыв окно консоли (должно сработать сочетание клавиш CTRL+ALT+T) и введите: sudo apt-get update
  4. Перейдите в папку, куда вы скачали установщик, и либо дважды щёлкните по нему, либо воспользуйтесь командной строкой: sudo apt install ./jamulus_3.12.3_ubuntu_amd64.deb (или для Raspberry Pi и т. д., как указано выше)
  5. После установки можно удалить файл и закрыть все консольные окна.

Обновления: Если вам нужно обновить Jamulus до более новой версии, а вы устанавливали его вручную, просто скачайте новый .deb-файл и переустановите его, как описано выше.

Настройте ваше оборудование

Для запуска клиент Jamulus должен подключиться к запущенному серверу JACK.Вам нужно выяснить какой звуковой сервер с низкой задержкой используется вашим дистрибутивом. - Если ваш дистрибутив использует JACK, смотрите как настроить JACK с помощью QjackCtl. - Если ваш дистрибутив использует PipeWire, смотрите как настроить PipeWire.

Настроить JACK с помощью QjackCtl

Рекомендуемый способ запуска сервера JACK - с помощью QjackCtl.

  1. Запустите QjackCtl. Вы увидите главную страницу утилиты Qt JACK Control.
  2. Настройте ваше звуковое оборудование следующим образом:
  • Выберите нужный звуковой интерфейс (в списке их может быть несколько — выберите правильный, так как его нельзя будет изменить, не остановив Jamulus и JACK).
  • Установите Частоту дискретизации в 48000.
  • Сначала установите Кадры/Период в 128 и Периоды/Буфер в 2.

Перезапустите JACK чтобы изменения приступили в силу и продолжайте ниже с секции Запуск Jamulus.

Найтройка PipeWire

PipeWire предоставляет собственный сервер JACK. Когда вы запускаете клиент Jamulus, PipeWire автоматически запускает сервер JACK. Тем не менее необходимо настроить несколько параметров. Вам нужно выставить ваш звуковой интерфейс в профиль “pro-audio” предварительно настроив параметры PipeWire’s “rate” и “quantum”. Вы можете найти больше информации по настройке на PipeWire wiki.

Для настройки системы: 1. Откройтеpavucontrol(звуковой мишкер) и выберите профиль “pro-audio” для вашего звукового оборудования на вкладке настройки.

  1. В Терминале используйте следующие две команды для выставления PipeWire’s rate и quantum: 
    pw-metadata -n settings 0 clock.force-rate 48000
pw-metadata -n settings 0 clock.force-quantum 128

    После этого, продолжайте ниже с секции Запуск Jamulus.

Запуск Jamulus

Когда JACK или PipeWire настроены, запустите Jamulus.

В случае возникновения проблем, обратитесь к странице устранения неполадок.
