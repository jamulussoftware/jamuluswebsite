|<nobr> `-d` or `--discononquit`</nobr>| disconnect all Clients on quit |
|<nobr> `-e` or `--directoryaddress`</nobr>| address of the Directory with which to register (or 'localhost' to run as a Directory) |
|<nobr> `--directoryfile`</nobr>| File to hold server list across Directory restarts. Directories only. |
|<nobr> `-f` or `--listfilter`</nobr>| Server list whitelist filter. Directories only. Format:<br/>`[IP address 1];[IP address 2];[IP address 3]; ...` |
|<nobr> `-F` or `--fastupdate`</nobr>| use 64 samples frame size mode |
|<nobr> `-l` or `--log`</nobr>| enable logging, set file name |
|<nobr> `-L` or `--licence`</nobr>| show an agreement window before users can connect |
|<nobr> `-m` or `--htmlstatus`</nobr>| deprecated, please use JSON-RPC instead |
|<nobr> `-o` or `--serverinfo`</nobr>| registration info for this Server.  Format:<br/>`[name];[city];[country as two-letter ISO country code or Qt5 QLocale ID]` |
|<nobr> `--serverpublicip`</nobr>| public IP address for this Server.  Needed when registering with a server list hosted behind the same NAT |
|<nobr> `-P` or `--delaypan`</nobr>| start with delay panning enabled |
|<nobr> `-R` or `--recording`</nobr>| set server recording directory; server will record when a session is active by default |
|<nobr> `--norecord`</nobr>| set server not to record by default when recording is configured |
|<nobr> `--noraw`</nobr>| disable raw audio |
|<nobr> `-s` or `--server`</nobr>| start Server |
|<nobr> `--serverbindip`</nobr>| IP address the Server will bind to (rather than all) |
|<nobr> `-T` or `--multithreading`</nobr>| use multithreading to make better use of multi-core CPUs and support more Clients |
|<nobr> `-u` or `--numchannels`</nobr>| maximum number of channels |
|<nobr> `-w` or `--welcomemessage`</nobr>| welcome message to display on connect (string or filename, HTML supported) |
