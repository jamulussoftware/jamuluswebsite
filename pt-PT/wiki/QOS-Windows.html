Utilização de QoS no Windows

Jamulus utiliza a Qualidade de Serviço (QoS) para mitigar atrasos no ‘‘jitter’’ da rede.

Se pretender explorar o efeito das definições não predefinidas, consulte as páginas 16 - 18 de RFC4594. Jamulus define o ‘‘byte’’ do Campo DS para 128 (ou 0x80) para selecionar DSCP/CS4 num cabeçalho de pacote IPv4 ou IPv6. Podem ser definidos outros valores, utilizando a opção -Q, exemplo, -Q [0..255]. Contudo, a maioria das pessoas não irão precisar disto.

As definições de QoS do Jamulus (incluindo a predefinição) estão definidas como 0 no Windows e macOS recentes por causa do sistema operativo. Para utilizar QoS no Windows, siga estas instruções. Tenha em atenção que poderá ter de repetir este procedimento sempre que o Jamulus for atualizado.

Na caixa de Pesquisa no menu Início, Digite: Local Group Policy Editor (Enter)
Na nova janela, (clique) no ícone do menu para exibir o painel de terceiros Ações
Ver o primeiro do painel do Editor de Política do Grupo Local
 Política do Computador Local
  Configuração do Computador
   Definições do Windows
    Política baseada em QoS (clique)
Veja o painel de terceiros (Ações) do Editor de Política do Grupo Local
 Política baseada em QoS
  Mais Ações
   Criar nova Política (clique)
    Nome da Política: Jamulus
    Especificar valor DSCP: 32
    Seguinte
    Esta política QoS aplica-se “Apenas” às aplicações com o nome Jamulus.exe
    Seguinte
    Seguinte
    UDP
    Terminar
